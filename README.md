# 🛡️ Denúncia Digital

Plataforma de denúncia anônima e conscientização sobre violações de Direitos Humanos no ambiente digital.

**Projeto Extensionista** — Tema Integrador V  
**Universidade:** UNIG EAD  
**Tema:** Direitos Humanos e o Universo Digital  
**ODS:** 16 — Paz, Justiça e Instituições Eficazes

---

## 📋 Funcionalidades

- Registro anônimo de violações digitais
- Dashboard dinâmico com gráficos em tempo real
- Página informativa sobre direitos digitais
- Coleta de dados demográficos sem identificação

---

## 🛠️ Tecnologias utilizadas

- Java 17 / 21
- Spring Boot 4
- Spring Data JPA
- Thymeleaf
- H2 Database
- Chart.js
- HTML5 + CSS3
